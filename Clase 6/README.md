Color HSB:  
Hue -> tono -> 0-360   
            Saturation -> saturación -> 0-100   
            Brightness -> brillo -> 0-100    
Se llama con colorMode (HSB) tiene 4 parámetros pero se puede agregar un quinto, rango alpha (transparencia)   

pushMatrix(); y popMatrix(); para modificar solo una parte del dibujo o de lo que se haga.
pushMatrix() permite mover, girar o cambiar de tamaño el espacio por un momento. Todo lo que se dibuje dentro va a tener esos cambios y, cuando llega a popMatrix(), el espacio vuelve a estar como antes. Las figuras dentro mantienen los cambios, pero lo que se dibuje después ya no se ve afectado.   
Modificar la posición, rotar o agranda elementos usando funciones translate(), rotate() o scale().   

El operador % (módulo) en Processing calcula el residuo de la división entre dos valores numéricos, ya sean enteros o con decimales.
